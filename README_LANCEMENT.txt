Lancement rapide :
1. Dezippez le dossier.
2. Ouvrez index.html dans Chrome ou Edge.
3. Pour la geolocalisation, il est preferable de lancer un petit serveur local :
   - double-cliquez sur LANCER_SITE.bat si disponible
   - ou lancez : python -m http.server 8000
   - puis ouvrez http://localhost:8000
